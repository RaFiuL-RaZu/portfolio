# Rafiul Razu Portfolio

Modern Flutter developer portfolio prepared for Vercel.

## Deploy with Vercel CLI

1. Extract the ZIP and open the folder in a terminal.
2. Run `npx vercel`.
3. Use `rafiul-razu-portfolio` as the project name.
4. Run `npx vercel --prod` for the production deployment.

If the project name is available, the default production address will be:

`https://rafiul-razu-portfolio.vercel.app`

You can also upload the project to GitHub and import the repository from the Vercel dashboard.
